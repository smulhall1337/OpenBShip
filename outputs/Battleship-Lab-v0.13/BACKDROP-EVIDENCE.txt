Battle backdrop and approved transparency - v0.11 - 2026-11-07

User direction: videos should be behind the game board as a background, and the
board should have transparency while a cinematic plays. User explicitly approved
30% transparency, with grid lines, ships, markers and controls kept opaque, and
full opacity restored afterward. This approval preceded implementation.

Composition is modern design. No original mask or alpha value is claimed recovered.
ClassicBackdrop derives two convex board regions and 22 grid lines per board from
the recovered native projection. Opaque HUD rectangles are documented in source.
Board interiors away from lines use alpha179/255 (nearest eight-bit representation
of70% opacity); grid-line neighborhoods1.5native pixels, outer borders and HUD use
alpha255. Areas outside the foreground mask use alpha0. Indexed source bytes and
original palette values are retained; alpha is applied only to a derived ARGB image.
Ships/markers/roster/results render afterward and receive no additional fade.
Existing marker tints/ship transparency already defined by earlier rendering remain
unchanged. Board pixels sample70%art plus30%video; raster rounding can differ by1.

BoardView draws the current finite movie frame as centered aspect-preserving cover
of the playfield, then foreground artwork and gameplay details. Cover can crop
movie edges; it does not stretch the4:3source. The separate106px playback row is
reserved by a TableLayoutPanel, so controls never cover the board. Native640x512
board coordinate/picking logic is unchanged and mapped to the available viewport.
The board viewport resizes when the playback row appears/disappears.
ClipStudy owns decoded bitmap/audio resources; BoardView borrows only the current
image on the UI thread. FrameChanged updates that reference/invalidation. Palette
changes replace/dispose the derived foreground without touching the movie state.
Completion/reset/failure remove the borrowed frame and restore opaque original art;
pause holds the cinematic frame and its transparency. Independent library unchanged.
