Deliberate modernization
Original text is Game Is Paused / Press Escape To Quit / Press P To Resume.
The recovered native Escape branch first pauses then requests a different
front-end/options state when already paused. The accepted modern binding keeps
both P and Escape toggling pause. Runtime therefore replaces only the middle
line with Escape Also Resumes. Native quit text is fixture-only, not advertised
as an available control. The dark readability scrim remains a modern overlay.
No native options/quit transition, general font system or multiplayer is claimed.
The legacy comparison preset and terminal result overlay retain their previous
modern typography. Original title/Solo/fleet/loading/ending flows remain as before.

game state, simulation and audio. Unsupported styles/characters/viewports fail
