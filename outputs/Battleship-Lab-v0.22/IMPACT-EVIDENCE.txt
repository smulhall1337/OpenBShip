Battleship impact reconstruction evidence - v0.10 - 2026-11-07

New behavior and correction
Movie mode now plays ship-specific hit/miss movies at Original target 1 and sinking
movies at all four settings. 0x424101 calls 0x419CE0 for a surviving hit at level
zero; 0x42411C calls 0x4177A0 for a miss. 0x4240CB ->0x424130 ->0x419270 selects
sinking playback. These are movie selectors, not merely board-effect setup. The
v0.9 report's board-only description of those paths was incomplete; its missing
level-zero and sinking movies are now filled in. v0.9 remains a preserved historical
comparison. User confirmed v0.9 firing/in-flight only; new feedback not yet accepted.

ClassicImpactOracle copies only three bounded selector ranges into a private x86
allocation. It checks the exact executable hash, 22/18/21 absolute relocations,
then protects code read/execute. Movie requests record their IDs; sound/graphics,
messages and cleanup are no-op stubs. Controlled RNG counts/returns and synthetic
ship records provide reproducible inputs. It does not launch the game or execute
full impact/damage/terminal/camera logic. The 252 rows are a numerical fixture grid,
not 252 played battles. Hit/miss selection uses mode flag 7 to expose the selected
ID through the main movie stub; sink uses confirmed Classic scenario 20. Conditional
owner/view/secondary-channel routing is not recovered by this fixture.

Fields used: ship +0 type (int), +0x0E total cells (short), +0x10 remaining HP
(short); hit caller has already decremented HP. Miss synthetic record's type is
weapon ID; fleet index +0x0C selects a 492-byte fleet whose kind is 1 in Classic.
Five fleet types/lengths are 7/5, 1/5, 2/3, 12/4, 4/2. Hit rows cover all remaining
HP values below total and eleven reachable weapon IDs; miss rows cover three RNG
results, sink rows two. The copied hit selector can request movie 0 at HP zero,
but actual caller takes the separate sink path first. Managed code follows that.

Modern choices and limits
Both sides use the existing full-field movie overlay; native owner/view routing,
secondary channels, priority/preemption and fades remain unverified. Each shot has
one firing, one travel and one eligible impact/sink movie. Simulation resolves at
travel completion once; the next turn and final result wait for the last movie.
Original terminal signaling can occur during sink setup; the modern defer is an
intentional presentation choice. Nominal 25 fps last-frame holds, safe audio-buffer
lifetime, mute/pause/reset, explicit failure pause and per-stage skip remain modern.
Missing native video can auto-progress; modern failures require explicit skip/reset.
Impact miss variants use a fourth isolated NativeRandom stream (seed XOR 0x42AC1),
only when level zero gun/torpedo misses need a draw. This retains accepted targeting,
firing, travel and HP histories. Full shared original RNG scheduling is not claimed.
No additional arbitrary board-animation delay has been invented. Board damage
smoke remains the earlier provisional presentation; exact full-loop timing unresolved.
