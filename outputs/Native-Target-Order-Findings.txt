Confirmed scope

calls 00423540. The newly implemented probe now executes the real target

720 bounded probes cover nine observation shapes, four difficulty levels,

Shapes: empty, masked 0/2/4, exhausted, sparse, single hit at either Y edge,

Every native draw/output/state was checked: 70,620 draws, including 69,180
inside the target selector. All four target call sites were observed:
0041CA94, 0041CB4B, 0041CB5B, 0041CB8D. The delivered pure weapon/movie and
target selectors, replayed consecutively with one managed NativeRandom,
agree on weapon, movie, coordinates, random-call count and final state in all
720 probes. Three newly owned helper processes produced byte-identical case
and draw traces despite independent allocations. The production game retains
its deliberately independent streams; this experiment adds no shared-RNG mode.

Independent shape/budget assertions verify edge pursuit, hit-chain direction,
masking and exhausted search budgets. On a fully resolved board, the original
returns its last sampled coordinate. Isolated hits with no open Y neighbor
are deliberately excluded: original code can retry indefinitely there. The
modern runtime's explicit stall handling remains intentional.
